Engineer deep-dive · Perception

Don't show it pixels.
Show it the UI tree.

A compact element list with real center coordinates, role tags, and the product title attached to every button.

Six identical ADDs → six distinguishable choices. This is 40% → 95%.

Engineer deep-dive · Guards

The model is wrong all the time. The harness catches it.

GROUNDING

Reject taps not on a real element.

INTENT MATCH

Action must serve the goal.

NAME MATCH

Adding milk? Then it's the milk card.

REPEAT-ADD

Don't add the same item twice.

FOCUS CHECK

No typing into an unfocused field.

LOOP DETECT

Re-screenshot; if nothing changed, escalate.
