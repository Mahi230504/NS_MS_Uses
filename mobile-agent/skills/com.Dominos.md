# Domino's (com.Dominos)

## Navigation
- Pizza menu is the home screen. Tap a pizza card → customization sheet (size, crust).
- Cart icon top-right or bottom; checkout flow asks delivery vs takeaway, then payment.

## Pitfalls
- Location + store-selection prompt on first launch — HITL.
- Payment screen is HITL-worthy; UPI PIN screens are secured (screencap may go blank).
