# Gmail (com.google.android.gm)

## Navigation
- Compose: red "+ Compose" FAB at bottom-right.
- Inbox list: each row is a thread; tap to open.

## Pitfalls
- **Never auto-tap "Send"** — emit need_approval before the paper-plane Send icon (top-right of compose screen).
- Multiple accounts may be present; the avatar at the top-right shows the active one. Check before composing.
