# Flipkart (com.flipkart.android)

## Navigation
- Search bar top; bottom tabs: Home, Categories, Notifications, Account, Cart.

## Pitfalls
- "Place Order" / "Pay & Place Order" — HITL.
- A "Plus / Plus Premium" upsell may interrupt the checkout flow; dismiss "Skip" or "Not now".
- Multiple sellers can list the same item — the highest-rated/Plus seller is usually the safe pick.
