# Flipkart (com.flipkart.android)

## Navigation
- Search bar top; bottom tabs: Home, Categories, Notifications, Account, Cart.

## Search and select
- For "<product>": tap the FIRST result. Multiple sellers can list the same
  item — Plus seller / highest-rated is the safe pick if a chooser appears.
- Don't open multiple product pages for one requested item.

## Cart and checkout — HITL mandatory
- "Place Order" / "Pay & Place Order" — need_approval with cart contents.
- A "Plus Premium" upsell may interrupt checkout — dismiss "Skip" / "Not now".
