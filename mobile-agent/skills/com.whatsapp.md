# WhatsApp (com.whatsapp)

## Navigation
- Bottom tabs: Chats, Updates, Communities, Calls.
- New chat icon (bubble + pencil, bottom-right) → search contact → opens chat.

## Pitfalls
- **Never auto-tap "Send"** — sending a message is irreversible. Compose the message and emit need_approval before tapping send.
- The send icon (paper plane) is at the bottom-right of the input.
- If the chat doesn't exist, tap the New-chat icon and search the contact's name.
