# Zomato (com.application.zomato)

## Navigation
- Bottom tabs: Delivery, Dining, Live, Profile.
- Search bar at top, scoped to the current tab.

## Pitfalls
- Location prompt + "for you" preferences sheet may interrupt first launch — HITL.
- "Pay now" and "Place order" are HITL-worthy.
- The cart icon sometimes hides under promo bottom-sheets; dismiss with the chevron.
