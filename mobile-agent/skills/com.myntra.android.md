# Myntra (com.myntra.android)

## Navigation
- Search top; bottom tabs: Home, Categories, Studio, Bag, Profile.

## Search and add
- For "<item>": tap the FIRST matching product. On the product page, size-chart
  sheets may pop — dismiss before adding to bag.
- Don't add multiple items for one request.

## Cart and checkout — HITL mandatory
- "Place Order" — need_approval with bag contents (item, size, qty, price).
